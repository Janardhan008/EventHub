Project Description

AI-Powered Autonomous QA Agent for EventHub is an end-to-end Agentic AI testing framework that autonomously analyzes application requirements, generates test scenarios, executes UI and API tests, detects failures, performs failure analysis, and generates actionable test reports.

The solution integrates Playwright with TypeScript, API testing, AI agents, Page Object Model, fixtures, test data management, and CI/CD to validate the complete EventHub user journey — from authentication and event discovery to search, filtering, event booking, and data validation.

An AI Orchestrator Agent coordinates specialized agents such as a Test Case Generation Agent, UI Automation Agent, API Testing Agent, Test Data Agent, Failure Analysis Agent, and Reporting Agent. Based on execution results, the agents collaborate to identify failures, classify defects, analyze probable root causes, and provide recommendations without requiring manual analysis of every failed test.
